Some failure requirements:
- skipping urls that are not complete
- skipping urls that return non 200 response
- failure to parse html pages can be skipped too

Writing to results to extracted-url.csv file:
- we write original url that was fetched -> with list of hyperlinks found
- even if no anchor tags are found, we write the original url that was fetched with empty hyperlinks list

Performance:
- batching writes to file should increase performance

Potential future improvements:
- according to how many logical cores and how much memory is available, we could make parsing and finding hyperlinks concurrent too
- Chunking the items and then parsing and finding hyperlinks for one chunk could be a possibility in the consumer along with concurrency might help throughput but this requires testing
- depending on how much memory is free, we could increase the concurrency further for the http fetches of html pages on our client and maybe increase the max per key which is basically the host we are connecting to, to test rate limits
